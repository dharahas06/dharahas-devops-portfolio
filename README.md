# Dharahas Naraharisetti — DevOps Portfolio

A responsive, animated portfolio made with plain HTML, CSS and JavaScript.

## 1. Open the project
1. Open this `it-portfolio` folder in VS Code or your editor.
2. Open `index.html` in your browser.

Recommended: install the VS Code extension **Live Server**, right-click `index.html`, then choose **Open with Live Server**.

## 5. Deploy / Update on Netlify
To publish your updated website to your Netlify site (`https://dharahas-devops-portfolio.netlify.app/`):
1. Open https://app.netlify.com/ in your browser and sign in.
2. Open your site `dharahas-devops-portfolio`.
3. Go to the **Deploys** tab.
4. Drag and drop this folder (`it-portfolio` or `devops-portfolio`) into the **"Need to update your site? Drag and drop your site output folder here"** area.
5. Your live site will immediately update with the new details!

## Files
- `index.html` — page structure and portfolio content
- `style.css` — dark theme, neon-green design, responsive layout and animations
- `script.js` — mobile menu and scroll reveal effects
