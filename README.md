# Dharahas — DevOps Portfolio

A responsive, animated portfolio made with plain HTML, CSS and JavaScript.

## 1. Open the project
1. Download and extract `devops-portfolio.zip`.
2. Open the extracted `devops-portfolio` folder in VS Code.
3. Open `index.html` in your browser.

Recommended: install the VS Code extension **Live Server**, right-click `index.html`, then choose **Open with Live Server**.

## 2. Personalize the website
Open `index.html` and use Ctrl+H (Find and Replace) to update:
- `DHARAHAS` — your display name
- `your.email@example.com` — your email address
- `your-github` — your GitHub username
- `your-linkedin` — your LinkedIn profile slug

Update the About and Skills text so it accurately reflects your experience.

## 3. Your profile photo
Your supplied photo is already included at `images/profile.jpg` and displayed in the hero section. To replace it later, overwrite that file with another image using the same filename.

## 4. Add real projects
The three project cards are starter examples. Replace their descriptions with projects you have actually completed.
For each card, update the `href="https://github.com/"` link to the matching GitHub repository.
Do not present practice examples as professional production experience.

## 5. Publish with Netlify
Easy method:
1. Open dharahas-devops-portfolio.netlify.app
2. Sign in or create a Netlify account.
3. Drag the extracted `devops-portfolio` folder onto the page.
4. Netlify will publish the site and provide a public URL.

## 6. Publish with GitHub Pages (alternative)
1. Create a GitHub repository, for example `devops-portfolio`.
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — dark theme, neon-green design, responsive layout and animations
- `script.js` — mobile menu and scroll reveal effects

Fonts are loaded from Google Fonts. If offline, the site falls back to system fonts.
